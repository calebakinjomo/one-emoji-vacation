Exactly one emoji for your dream vacation — my entry for the make.fun
one-emoji bounty. One single emoji, nothing else: a desert island, the
postcard version of a dream vacation. White sand, one palm tree, open sea
and nowhere to be.

> 🏝️

`main.py` (Python 3, standard library only) prints exactly that emoji and
writes the same emoji to `entry.txt` in the output directory.
